# OfficeGhost Desktop

Desktop-клиент OfficeGhost на React, TypeScript и Tauri 2.

## Возможности текущей версии

- чат по локальному индексу документов;
- источники для каждого ответа;
- индексирование PDF, DOCX, XLSX, PPTX, TXT, Markdown, CSV, JSON, HTML и RTF;
- выбор нескольких папок, автоиндексация при первом запуске и фоновое обновление;
- поиск по имени, пути и содержимому с поддержкой русских запросов;
- добавление отдельных документов прямо в чат;
- создание настоящих DOCX/XLSX, а также TXT и Markdown из ответа;
- глобальный шорткат и управление расписанием обновления;
- локальная модель через Ollama.
- личный кабинет приложения с входом через системный браузер и возвратом по защищённой ссылке `officeghost://`.

## Запуск интерфейса

```bash
npm install
npm run dev
```

## Нативный запуск

После установки Rust:

```bash
npm run tauri:dev
```

## Проверка

```bash
npm run build
cargo check --manifest-path src-tauri/Cargo.toml
cargo check --manifest-path rust-indexer/Cargo.toml
```

## Как пользоваться

1. Откройте «Библиотека» и нажмите «Добавить папку» либо дождитесь первичной индексации стандартных папок Documents, Desktop и Downloads.
2. Следите за живым прогрессом в нижней панели. После статуса «Индекс актуален» документы доступны в поиске и чате.
3. Для умных сводок нажмите «Установить локальный ИИ». Нужна установленная Ollama; обычный поиск и ответы фрагментами работают без модели.
4. Кнопка скрепки добавляет отдельный файл в текущий вопрос без добавления всей папки в библиотеку.
